NAME
    helpers - the PHP global helper functions (helpers.php)

SYNOPSIS
    No import, no facade, no use statement - these are plain global functions,
    loaded for every request and every command:

        return response_form_error('Validation failed', ['email' => 'Required']);

        $host = array_get($config, 'services.mail.host', 'localhost');
        $safe = safe_html($params['body']);
        $size = bytes_to_human($file->size);

        exec_safe('mysqldump ' . escapeshellarg($db), $output, $exit);

        shouldnt_happen('a task ran with no site context');

DESCRIPTION
    RSpade ships one flat set of global helper functions rather than a family of
    static facades. There is nothing to import and nothing to remember about
    WHERE a utility lives: if it is a general-purpose operation - escape this,
    read that dot path, format these bytes, run this command - it is a global
    function with a descriptive underscore_case name.

    ALWAYS use these instead of hand-rolling. A hand-rolled byte formatter, dot-
    path reader, HTML escaper or subprocess wrapper is not merely redundant; it
    diverges. bytes_to_human() renders identically on the server and in the
    browser because the JS mirror was written against this implementation, and
    exec_safe() is the ONE place the framework guarantees bash (never dash) is
    the shell.

    Many of these functions exist in BOTH languages with matching semantics, so
    a value formatted server-side and the same value formatted client-side read
    identically: safe_html(), htmlbr(), bytes_to_human(), linkify_text(),
    linkify_html(), snake_to_camel(), camel_to_snake(), safe_string(),
    console_debug(), full_url_to_short_url(), short_url_to_full_url(),
    json_encode()/json_decode() (JS only, wrapping the natives) and
    shouldnt_happen(). See rsx:man js_functions for the JavaScript side.

    Some names deliberately SHADOW a Laravel or Illuminate concept
    (array_get/array_set/array_first/array_last mirror Arr::, is_blank mirrors
    blank()). That is intentional: one vocabulary, in one style, callable from
    anywhere including a Blade template.

    Functions prefixed with a single underscore (_rsx_file_hash_for_build,
    _linkify_content, _paths_on_same_filesystem, ...) are framework-internal.
    Do not call them from application code.

API REFERENCE

  Type and blank tests

    is_blank($value): bool
        True for null, a whitespace-only string, an empty array or an empty
        Countable. Numbers and booleans (including 0 and false) are NOT blank -
        this is the "did the user actually give me something" test, not empty().

    is_associative_array(array $array): bool
        True when the array has any non-sequential key.

    is_ide(): bool
        True when running inside an IDE analysis/completion context.

    is_loopback_ip(): bool
        True when the current request comes from localhost / 127.0.0.1 / ::1.
        A posture check for dev tooling - never a security boundary.

  Arrays

    array_only(array $array, array $keys): array
        Whitelist: keep only the named keys.

    array_except(array $array, array $keys): array
        Blacklist: drop the named keys.

    array_get(array $array, string $key, $default = null)
        Dot-path read: array_get($a, 'user.address.city'). Returns $default when
        any segment is missing. A literal key containing dots is matched first,
        before the path is split.

    array_set(array &$array, string $key, $value): void
        Dot-path write, BY REFERENCE, creating intermediate arrays as needed.

    array_first(array $array, ?callable $callback = null, $default = null)
    array_last(array $array, ?callable $callback = null, $default = null)
        First/last element, optionally the first/last matching the callback.

    array_pluck($array, ?string $key = null): array
        Extract one key's value from a collection of arrays/objects.

    array_flatten(array $array, $depth = INF): array
        Flatten nested arrays into one level.

    array_merge_deep(array &$target, array &$source): array
        Recursive merge - the mechanism behind config overrides. Both arguments
        are by reference; the merged array is also returned.

    ksort_recursive(array &$array, int $sort_flags = SORT_REGULAR): void
        Key-sort an array and every nested array. Used to make a structure
        hashable in a stable order.

    object_to_array_recursive($object)
        Convert objects to arrays all the way down.

  Strings and HTML

    safe_html(string $html): string
        HTMLPurifier sanitization for WYSIWYG/rich-text content that is MEANT to
        carry markup. Use when the string is supposed to contain HTML.

    htmlbr(?string $str): string
        Escape, then convert newlines to <br>. The common pairing for plain text
        that has line breaks. NOT interchangeable with safe_html(): htmlbr()
        assumes the input is TEXT and escapes any markup in it; safe_html()
        assumes the input is MARKUP and filters the dangerous parts out.

    text_to_html_with_whitespace(string $text): string
        Escape and preserve indentation and runs of spaces as well as newlines -
        for rendering log output, stack traces, or pasted plain text.

    linkify_text(?string $content, bool $new_window = true): string
        Escape plain text and turn bare URLs, hostnames and email addresses into
        anchors.

    linkify_html(?string $content, bool $new_window = true): string
        Same, for content that ALREADY contains markup - existing anchors are
        left alone rather than nested.

    safe_string(string $string, int $max_length = 64): string
        Reduce a string to something usable as an identifier (variable, function
        or file-name fragment).

    snake_to_camel(string $string, bool $capitalize_first = false): string
    camel_to_snake(string $string): string
        Case conversion, matching the JS twins exactly.

  Filesystem and paths

    ensure_directory(string $path, int $permissions = 0755): bool
        Create a directory (recursively) if it does not exist.

    file_put_contents_safe(string $file, string $content)
        Atomic write: a concurrent reader never observes a half-written file.
        Use this for anything another process may be reading - build artifacts,
        caches, generated code.

    rsxrealpath(string $path): string|false
        Normalize . and .. WITHOUT following symlinks. PHP's realpath() resolves
        them, which is wrong in this codebase: /rsx and system/.env are symlinks
        whose LOGICAL path is the meaningful one. Use rsxrealpath() for any path
        that may cross one.

    relative_path(string $path, ?string $base = null): string
        The project-logical relative path (manifest keys, framework path
        constants): base_path()-relative, except that relocated storage paths
        keep their 'storage/...' spelling.

    rsx_project_file_path(string $relative_path): string
        The inverse: resolve a project-logical relative path to an absolute one.
        'storage/...' resolves against the RELOCATED storage root
        (storage_path()); everything else against base_path(). NEVER join a
        storage path onto base_path() by hand - base_path() is system/.

    file_extension(string $path, bool $double = true): string
        Extension, handling double extensions (.blade.php) when $double.

    copy_directory(string $source, string $destination, array $ignore = []): bool
    rmdir_recursive(string $dir, bool $delete_self = true, array $ignore_dirs = [])
    make_temp_directory(string $prefix = 'rsx_', ?string $base = null): string
        Recursive copy, recursive delete, and a temp directory.

  Views

    rsx_view(string $id, array $data = [], array $merge_data = [])
        Resolve a Blade view by its RSX ID (the @rsx_id directive) rather than
        by file path, and return the view instance. This is what a controller
        returns for a server-rendered page.

    rsx_view_path(string $id): string
        The Laravel view path behind an RSX ID (used by the RSX Blade
        directives).

    rsx_body_class(): string
        The current view's RSX ID, for use as a body class in a layout.

  HTTP responses

    All of these build the standard Ajax error envelope. The client-side
    handlers key on the error code, so use the specific helper rather than
    hand-building an array.

    response_error(string $error_code, $metadata = null)
        The general form. Codes: Ajax::ERROR_VALIDATION, ERROR_NOT_FOUND,
        ERROR_UNAUTHORIZED, ERROR_AUTH_REQUIRED, ERROR_FATAL, ERROR_GENERIC.

    response_form_error(string $message, array $field_errors = [])
        Validation failure with per-field messages, keyed by field name - what
        Rsx_Form renders inline against each input.

    response_unauthorized(?string $message = null)
    response_not_found(?string $message = null)
    response_auth_required(?string $message = null)
    response_fatal_error(?string $message = null, array $details = [])

    rsx_absolute_url(string $path): string
        A relative path as an absolute URL on the application hostname. Always
        https (APP_URL is https-enforced at boot). For a same-origin link in
        HTML, use Rsx::Route() instead - this is for emails, webhooks and
        anything leaving the page.

  Shell

    exec_safe(string $command, array &$output = [], int &$return_var = 0,
              array $env = []): string|false
        THE sanctioned subprocess wrapper. Application and framework code do not
        call shell_exec/exec/system/passthru/proc_open directly.

        - Runs the command through BASH explicitly (array-form proc_open of
          ['bash','-c',...]), so /bin/sh (dash on our platforms) never sees it.
        - stderr is merged into stdout; $output receives the lines and the last
          line is returned, matching exec()'s shape.
        - stdin is /dev/null, so a command that reads it gets EOF instead of
          hanging.
        - $return_var receives the real exit status; a fork/exec failure returns
          false with $return_var = -1 rather than reporting a success nobody
          observed.
        - $env is MERGED over the current environment. Pass a secret here, never
          on the command line, where ps would expose it.

        Escape every interpolated value with escapeshellarg(). For an artisan
        subprocess use Rsx_Artisan, NOT this (see rsx:man locks).

    shell_exec_pretty(string $command, bool $real_time = true,
                      bool $throw_on_error = false)
        A console-facing wrapper that echoes the command and streams its output
        for a human watching a command run. For tooling output, not for
        capturing a value.

    command_exists(string $command): bool
        Whether a binary is on PATH. The right guard before a __skip() in a test
        or an INFO row in a health check.

  Formatting

    bytes_to_human($bytes, int $precision = 2): string
        A faithful rendering of an ACTUAL size ("1.5 MB"); "---" for a
        non-number. Do NOT use it to render the configured upload ceiling - that
        has its own label function (Ajax::max_file_size_human(); see
        rsx:man file_upload).

    ini_bytes($value): int
        A PHP ini size value in BYTES. ini_get() returns shorthand VERBATIM
        ("8M", "1G") - a string. Comparing that to a byte count produces
        confident nonsense, so there is one parser and this is it. "-1"
        (unlimited) and "" both return 0, meaning "no ceiling here"; the caller
        decides what that implies.

    duration_to_human($seconds, bool $round_to_whole_value = false): string
        "45 seconds", "2 minutes and 30 seconds", "2 hours and 30 minutes"; with
        $round_to_whole_value, only the largest unit.

    random_hash(int $bytes = 32): string
        Cryptographically secure hex string. Use this for tokens, keys and
        unguessable identifiers - never rand(), mt_rand() or uniqid().

  URLs

    full_url_to_short_url(?string $url): ?string
        Strip the protocol (and trailing slash) for display or storage.

    short_url_to_full_url(?string $url): ?string
        The inverse - add the protocol back.

    validate_short_url(?string $url): bool
        Whether a protocol-less string looks like a valid domain.

  Debug and failure

    rsx_dump_die(...$values): void
        Enhanced var_dump + die, with the calling file/line and a stack trace.
        The preferred temporary debugging output. Never ship one.

    console_debug(string $channel, ...$values): void
        Channel-filtered debug output (CONSOLE_DEBUG_FILTER), stripped in
        production builds. Same function name and semantics in JS.

    shouldnt_happen(?string $message = null): void
        An impossible condition was reached. ALWAYS throws, with location and
        context. This is the fail-loud primitive: use it instead of returning
        early, substituting a default, or writing a comment about a case that
        "cannot" occur.

EXAMPLES

    Dot paths over a decoded payload:

        $payload = json_decode($raw, true);

        $city = array_get($payload, 'customer.address.city');           // null if absent
        $tier = array_get($payload, 'customer.plan.tier', 'standard');  // with a default

        array_set($payload, 'meta.processed_at', Rsx_Time::now_iso());

    Escaping vs sanitizing - a security decision, not a style one:

        // The field is PLAIN TEXT the user typed. Escape it; keep line breaks.
        $notes_html = htmlbr($record->notes);

        // The field came from a WYSIWYG editor and is SUPPOSED to be markup.
        $body_html = safe_html($record->body_html);

        // NEVER the other way around: safe_html() on plain text lets a user's
        // literal "<b>" become bold; htmlbr() on editor output shows the tags.

    Running a subprocess safely:

        $output = [];
        $exit   = 0;

        exec_safe(
            'pdftotext ' . escapeshellarg($path) . ' -',
            $output,
            $exit,
            ['LC_ALL' => 'C']          // env, merged - secrets go here, not in the string
        );

        if ($exit !== 0) {
            throw new \RuntimeException('pdftotext failed: ' . implode("\n", $output));
        }

    Comparing a configured limit against an actual size:

        $ceiling = ini_bytes(ini_get('post_max_size'));   // 0 means "no ceiling"

        if ($ceiling > 0 && $size > $ceiling) {
            return response_error(Ajax::ERROR_VALIDATION,
                'File exceeds ' . bytes_to_human($ceiling));
        }

    Paths that cross a symlink or reach storage:

        $manifest_key = relative_path($absolute);            // project-logical
        $cache_file   = rsx_project_file_path('storage/rsx-tmp/thumbs/' . $key);
        $normalized   = rsxrealpath($base . '/../rsx/models');   // does NOT follow links

    A validation failure the form renders inline:

        if (empty($params['email'])) {
            return response_form_error('Validation failed', [
                'email' => 'Email address is required',
            ]);
        }

RSX VS LARAVEL
    Laravel:  Arr::get(), Arr::only(), Str::snake(), Str::slug(), blank(),
              Storage::, Process::run(), response()->json() - static facades,
              each imported per file, several of them requiring the container.
    RSX:      one flat global namespace of underscore_case functions, always
              loaded, callable from a controller, a model, a command, a Blade
              template or a task with no import at all.

    The overlaps are deliberate replacements, not duplicates:

        Laravel                     RSX
        Arr::get()/set()            array_get()/array_set()
        Arr::only()/except()        array_only()/array_except()
        Arr::first()/last()         array_first()/array_last()
        blank()                     is_blank()
        Str::snake()/camel()        camel_to_snake()/snake_to_camel()
        realpath()                  rsxrealpath() (does not follow symlinks)
        Process::run()/shell_exec() exec_safe() (explicit bash, merged stderr)
        response()->json([...])     response_error() and friends (one envelope
                                    the client handlers already understand)
        report()/abort()            shouldnt_happen() (throws; no silent path)

    Laravel's helpers are free to return a soft failure. These are not: the
    framework's fail-loud rule means a helper that cannot do its job throws
    rather than returning something plausible. exec_safe() returning false with
    $return_var = -1 is the shape - never a quiet empty string.

TROUBLESHOOTING

    "Call to undefined function ..."
        The name is wrong, or the function is one of the _-prefixed internals.
        These are globals loaded at boot; there is no import that could be
        missing. Check the spelling against the API REFERENCE above.

    "array_get() returns the default for a key I can see."
        The path is split on dots, so a segment containing a dot cannot be
        addressed - except as the WHOLE key, which is matched first. Also note
        array_get() reads arrays, not objects: decode with
        json_decode($raw, true).

    "My HTML shows up as tags" / "my user's HTML rendered as markup."
        The escape/sanitize pair is backwards. Plain text -> htmlbr(); editor
        markup -> safe_html(). See the EXAMPLES.

    "exec_safe() reports success but the command clearly failed."
        Check $return_var, not the return value: the return value is the last
        OUTPUT LINE (matching exec()), and only false signals that the process
        could not be started at all.

    "My shell one-liner works in a terminal and fails from PHP."
        It probably relied on a bashism and something else ran it under dash.
        exec_safe() always uses bash; a raw shell_exec()/system()/string-form
        proc_open() does not. Route it through exec_safe().

    "A size comparison against an ini limit is wrong."
        ini_get() returned "8M" - a string. Wrap it in ini_bytes(). Remember 0
        means unlimited/unset, so a bare `$size > $limit` treats "unlimited" as
        "reject everything".

    "realpath() broke on this box."
        It followed a symlink (/rsx, system/.env). Use rsxrealpath().

    "A storage path resolved into system/."
        base_path() IS system/. Use storage_path(), or
        rsx_project_file_path('storage/...').
