# Thumbnails — pointer

The thumbnail caching system (two-tier dynamic/preset cache, filename format, LRU
tracking, quota enforcement, WebP output, non-image substitution, the renderer
registry, and the `rsx:thumbnails:*` commands) is documented in:

- `rsx:man thumbnails` — the full contract
- `rsx:man file_upload` — `has_thumbnail()`, `get_thumbnail_url()`, the upload payload
- `rsx:man libreoffice` — the shared headless soffice slot pool
- Skill: `rspade:file-attachments`
